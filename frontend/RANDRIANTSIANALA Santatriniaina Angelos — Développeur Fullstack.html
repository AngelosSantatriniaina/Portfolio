À propos

Développeur polyvalent : je conçois des applications métier complètes — back-end Spring Boot, API REST, bases de données relationnelles — et je livre l'interface sur le support adapté : React JS sur le web, JavaFX sur desktop, Flutter sur mobile.

Mes projets vont de la gestion des ressources humaines (personnel et congés) à la gestion de quincaillerie, en passant par la création de plans de maison en 2D — sans compter de nombreux projets personnels.

J'administre également les environnements sur lesquels ces applications sont déployées : serveurs Linux/Windows, réseaux, sécurité, sauvegardes et supervision.
